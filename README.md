# 实体死亡掉落物动量 Entity Die Loot Momentum，简称 E-D-L-M(?)

一个小附加包，可以给非玩家实体死亡时的掉落物加个动量

# 这是什么？

这是一个 我的世界基岩版(Minecraft Bedrock Edition) 的 附加包(Addon)，使用基岩版的 JavaScript 脚本编写，虽然代码其实基本也都是 AI 写的……

这个可以让非玩家实体死亡后的掉落物像玩家死亡时那样，可以爆出来，飞出去，散落一地这样，而不是像原版那样直接硬在原地不动的(虽然原版好像有时候可能大概应该或许也会出现飞出去的效果，但好像也都没那么明显的)

ps: 原版好像只有 minecraft:loot 组件掉落出来的物品不会有速度，其他的比如生物装备的物品盔甲，还有背包里的物品之类的，死亡时也会跟这个附加包要实现的功能一样，但 minecraft:loot 并没有动量！所以这个附加包并不是完全没用，而且这个附加包还可以自定义动量噢！

虽然可能会乱飞，掉到莫名其妙的地方里，不好捡之类的，不过至少比原版直接硬在原地不动好多了吧(?)

还可以用 /scoreboard players set "掉落物动量" bz_loot_momentum <整数> 来修改掉落物飞散出去的倍率，虽然只能输入整数……

# 版本要求

Minecraft Bedrock Edition 1.21.100 及以上

虽然不确定更低版本还能不能使用，但我设置的最低版本就是1.21.100，@minecraft/server 用的也是 2.0.0 版本的，如果能用的话也可以尝试自己改一下

# 如何使用？

下载后前往文件管理器里，在 Download 文件夹里找到该附加包文件，然后鼠标右键或手机长按，用 Minecraft 打开，或分享给 Minecraft，然后在自己的世界里，添加该行为包，最后进入存档就能使用了

# 已知问题

掉落物有时候可能会乱飞，比如掉进岩浆里掉进虚空里之类的，总之就是老是掉到莫名其妙的地方，导致捡不到了，就很难受

掉落物检测是新的还是旧的甚至还是用记分板来检测的，记分板分数低于 2 时就会给动量，分数高于 2 时就会 continue; (跳过)

"明明都已经用上脚本了，你还用什么指令来检测，你这不就是典型的命令方块思维嘛！笨蛋！笨蛋！笨！"

有时候可能会因为实体死亡时附近有新的掉落物生成导致给其他的掉落物也加一个动量

也有时候会因为实体距离掉落物太远，导致找不到掉落物，而没有动量

同一个物品的掉落物有时候会堆叠在一起，比如说用一把抢夺三的剑杀了一头牛，掉了4块牛排，但实际上其实只有一个掉落物实体能炸出去，不像Java版那样，可以每个物品都是一个掉落物实体，炸出去后再重新堆叠

不过总之大概应该能用就行了吧(?)
